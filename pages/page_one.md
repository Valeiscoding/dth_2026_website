# On the bright side: Advantages of open source software

Let’s deep dive into some of the advantages that open source software offers.

## Knowledge Hub

All open source projects can be seen as an open knowledge hub. Because of its nature, where everyone can read the code of a project, it technically can function as a public library, where anyone interested can choose a book and read it to gain knowledge on a specific topic (in this case, a specific project to learn how this was built). People can log in and learn from those with more experience to strengthen their own coding skills. Therefore, it is a great tool for people that are beginners and would like to improve their skills.

## Transparent and creative development 

Having a software that works on an open source basis allows for collaboration from people with different perspectives, experiences, and backgrounds. This mix of elements can result in a more creative development, since different members can point out blind-spots and gaps that one singular person might not think of. At the same time, having more mind thinking together helps to have a faster development, as well as more vigilant eyes watching out for faults in the code, which can also translate into quicker bug fix suggestions.
